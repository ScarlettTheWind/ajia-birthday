# 阿贾的24岁生日纪念册

## 自动版本备份

`版本备份/` 下按 `v001_时间`、`v002_时间` 另存完整版本，不覆盖旧版本。时间采用 UTC，具体创建时间见各目录的 `备份信息.json`。每次运行 `node build-inline.mjs`（或 `npm run build`）都会自动备份生成后的版本；这不是后台文件监控，手动修改后请运行此命令。也可运行 `node backup-version.mjs` 单独保存快照。今后本项目的助手更新流程已在 `AGENTS.md` 中要求执行备份。

每份备份含网站、源码、说明和逐文件 SHA-256 校验信息。恢复时将所需版本复制到一个新文件夹，再运行 `node server.mjs`；不要直接在历史备份内修改，以保留原件。备份保存在本机同一磁盘，未上传云端。

完整网站在 `dist/`，不需要安装依赖。安装 Node.js 后，在这个文件夹运行 `node server.mjs`，浏览器打开 http://localhost:4174 。双击 HTML 也可浏览和点击互动；摄像头请使用 localhost 或 HTTPS。

## 换成我们的回忆

修改 `dist/config.js` 可替换昵称、五年故事、照片、24句祝福、生日信、结尾与音乐，修改后运行 `node build-inline.mjs` 更新页面。基础交互直接内嵌在页面里，避免脚本独立加载失败导致按钮无响应。五年时间轴和信里的方括号内容是明确标注的示例，请在送出前换成真实经历。

把合照放到 `dist/photos/`，将 photos 中的 src 从空字符串改成 `photos/合照.jpg`。建议使用英文文件名。图片在相册中可点击放大。years 每项还支持第4项照片地址、第5项日期。无照片时显示占位卡片，不使用陌生人照片。

音乐默认是点击后播放的轻柔合成旋律；如有自己有权使用的音乐，放入 `dist/music/`，把 music 改为 `music/birthday.mp3`。生日为2002年9月25日，页面为2026年9月25日24岁生日准备。

## 摄像头

点击“用手势吹蜡烛”→“开启摄像头”，允许访问后张开手掌，左右明显挥动约2～3秒。使用 MediaPipe 的真实21点手部检测，只请求视频权限；画面、手部坐标不上传，不录制、不保存。首次使用需联网下载固定版本识别库、WASM和模型；浏览器会向 jsDelivr 和 Google 发送这些静态资源请求。外部字体来自 Google Fonts，无法访问时会使用本机字体。

识别根据张开手掌、短时横向移动幅度、速度和连续性累计进度；静止、轻微抖动、握拳不会完成。停止挥手会衰减。完成、关闭、切换到后台或滚离蛋糕区域会释放摄像头。模型加载30秒超时会停止摄像头并提供点击备用方式。不同光线和设备会影响识别速度。

在微信内或嵌入式预览中摄像头可能受限制，可复制链接到手机系统浏览器。关闭摄像头按钮也可以取消等待中的初始化；若权限对话框仍开着可选择取消。没有摄像头也能用“点击吹灭蜡烛”完整体验。

## 部署与分享

将整个 `dist` 文件夹作为静态网站部署到支持 HTTPS 的托管服务即可，不需要服务器接口、数据库或登录代码。服务配置：无构建命令，发布目录为 `dist`。代码中的 `.openai/hosting.json` 用于当前 Sites 项目，其他托管平台无需它。

Sites 默认私有，私有链接只有网站所有者可看；给阿贾分享前，需要在 Sites 中调整访问范围。不要把 localhost 链接发给她，它只能在本机打开。公开发布前请确认照片和回忆适合该可见范围。

验证：`npm run check` 检查语法；`npm test` 验证静止、抖动、握拳、持续挥手及丢失手掌的进度逻辑。自动测试使用模拟坐标，无法代替真实设备与光线下的摄像头体验。

识别接口参考：https://developers.google.cn/edge/mediapipe/solutions/vision/hand_landmarker/web_js
